# OwlFly — Fresh Cinematic Animation

## Production outputs

- `OwlFly_Fresh_Cinematic_1080x1920.mp4` — 14 s, vertical 9:16, 30 fps, H.264/AAC.
- `owlfly_promo_poster.png` — final brand poster.
- `owlfly_flight_poster.png` — in-flight poster.
- `OwlFly_Figma_Storyboard.svg` — five-panel storyboard. Import this SVG into a Figma canvas, or use the five separate scene PNGs.
- `owlfly_original_score.wav` — standalone original atmospheric audio score (locally synthesized).
- `index.html` — quick self-contained playback and source-frame viewer.
- `manifest.json` / `quality_report.json` — provenance and file verification.
- `build_owlfly_animation.py` — reproducible source. Requires Python Pillow, NumPy and ffmpeg.

## Creative direction

A cinematic illustration of OwlFly's world, emphasizing controlled flight, readable environmental changes, and discovery. Not intended as direct gameplay capture or proof of any unreleased mechanics. Keep the owl readable in the middle safe lane.

## Usage

Keep text within portrait safe margins when posting to Reels, Shorts, TikTok or Facebook. Use the original 1080 × 1920 MP4 for distribution, do not re-encode repeatedly. Original soundtrack is not an ElevenLabs generation, and this SVG is an importable source rather than a verified live Figma cloud document.
